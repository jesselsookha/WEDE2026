## Welcome

Welcome to the official course repository for **Introduction to Web Development (WEDE5020)** for 2026.

This repository accompanies the in-class lectures, practical sessions, and your assignments. It brings together the coding examples we build together in class, the expanded notes that support each learning unit, and the support documents you will need for your assessments.

This subject introduces the core building blocks of the modern web — combining hands-on coding with a conceptual understanding of how websites are planned, built, published, and measured.

---

## What We Cover

Over the semester, we explore:

- **HTML** — the structure of web pages
- **CSS** — styling and layout
- **Responsive Web Design** — making websites work across devices
- **JavaScript** — adding interactivity and behaviour
- **Publishing & Analytics** — launching sites, measuring performance, and SEO fundamentals

The repository is organised into three folders:


| Folder | Purpose |
|--------|---------|
| **`docs/`** | The expanded notes for each learning unit. These accompany the lectures and are numbered in sequence from introductory theory through to publishing and analytics. |
| **`code/`** | In-class coding examples built with students during practical sessions. Use these as references when completing your own work. |
| **`support/`** | Subject-specific support materials — assignment checklists, submission guides, project templates, and other documents to help you meet the requirements of your official briefs. |

---

## About the Notes (`docs/`)

The notes in the `docs/` folder are organised into **numbered documents**, each aligned to one or more learning units:

| Topic | Documents |
|-------|-----------|
| **Introduction to Web Development** | 01–03 — Theory: Why websites matter, success factors, strategy & measurement |
| **File Structure & Tooling** | 04 — File structure and Visual Studio Code |
| **HTML** | 05–10 — Basics, content tags, tables & forms, best practices, full anatomy |
| **CSS** | 11–18 — Introduction, syntax & selectors, box model, typography, Flexbox, Grid, animations, best practices |
| **Responsive Web Design** | 19–24 — Introduction, media queries, mobile-first, responsive images, navigation, frameworks, testing, reflection |
| **JavaScript** | 25–35 — Introduction, syntax, functions & conditionals, loops & arrays, DOM, events, form validation, project sprint, libraries & APIs, capstone |
| **SEO, Publishing & Analytics** | 36–41 — SEO fundamentals, SEO for developers, publishing workflow, FTP & deployment, analytics, launch checklist |

These documents are intended to be read alongside the class sessions. They expand on the concepts discussed in class, provide annotated code examples, and include reflection questions to check your understanding.
