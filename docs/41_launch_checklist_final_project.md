## ✓ Pre-Launch Development Checklist

### 🔹 Code Quality

- [ ] HTML is valid (passes W3C validation)
- [ ] CSS is valid (passes W3C CSS validation)
- [ ] JavaScript is functional and error-free (check browser console)
- [ ] Code is indented and formatted consistently
- [ ] Code is commented where necessary

### 🔹 Content

- [ ] All content is proofread and error-free
- [ ] No placeholder text remains (e.g., "Lorem ipsum")
- [ ] All links work (internal and external)
- [ ] All images load correctly
- [ ] Descriptive alt text on all meaningful images

### 🔹 Navigation

- [ ] Navigation is consistent across all pages
- [ ] All pages are accessible from the main navigation
- [ ] A clear path exists to return to the homepage
- [ ] Footer contains necessary links (privacy, contact, etc.)

### 🔹 SEO

- [ ] Each page has a unique, descriptive `<title>` (under 60 characters)
- [ ] Each page has a unique `<meta name="description">` (under 160 characters)
- [ ] One `<h1>` per page with proper heading hierarchy
- [ ] Semantic HTML tags used (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`)
- [ ] Clean, readable URLs (use hyphens, not underscores or query parameters)
- [ ] Sitemap.xml created (if multiple pages)
- [ ] robots.txt file in root directory

### 🔹 Responsive Design

- [ ] Site works on mobile, tablet, and desktop
- [ ] Viewport meta tag is present
- [ ] Images scale correctly
- [ ] Touch targets are at least 44px
- [ ] No horizontal scrolling on any device

### 🔹 Accessibility

- [ ] Alt text on all images
- [ ] Proper colour contrast (4.5:1 minimum for text)
- [ ] Keyboard-navigable
- [ ] Focus indicators are visible
- [ ] ARIA labels where needed
- [ ] Form labels associated correctly

### 🔹 Performance

- [ ] Page loads in under 3 seconds
- [ ] Images are optimised (compressed, appropriate size)
- [ ] CSS and JavaScript are minified
- [ ] Lazy loading used for below-the-fold images
- [ ] Passes Google PageSpeed Insights (at least 90 on mobile)

### 🔹 Security

- [ ] HTTPS is enabled (SSL certificate)
- [ ] Forms use secure submission methods (POST)
- [ ] No sensitive data exposed in URLs

---

## Pre-Launch Publishing Checklist

### 🔹 Domain & Hosting

- [ ] Domain name is registered
- [ ] Hosting account is set up
- [ ] Domain is connected to hosting (DNS configured)
- [ ] Site loads at the correct domain

### 🔹 Deployment

- [ ] All files are uploaded to the correct directory
- [ ] File permissions are set correctly (644 for files, 755 for directories)
- [ ] 404 page is created and configured

### 🔹 Testing

- [ ] Site is tested on multiple browsers (Chrome, Firefox, Safari, Edge)
- [ ] Site is tested on multiple devices (phone, tablet, desktop)
- [ ] All forms are tested (submission and validation)
- [ ] All links are tested

---

## Post-Launch Analytics Checklist

### 🔹 Setup

- [ ] Google Analytics (GA4) is installed and tracking
- [ ] Google Search Console is set up and verified
- [ ] Conversion tracking is configured (if applicable)

### 🔹 Monitoring

- [ ] Analytics is checked daily for the first week
- [ ] Bounce rate is monitored
- [ ] Top pages are tracked
- [ ] Traffic sources are reviewed

### 🔹 Goals

- [ ] At least one SMART goal has been defined
- [ ] Goal tracking is set up in analytics

---

## Post-Launch Maintenance Checklist

### 🔹 Ongoing Tasks

- [ ] Content is updated regularly (every 1-2 months)
- [ ] Links are checked for broken links
- [ ] Performance audits are run monthly
- [ ] Analytics are reviewed monthly
- [ ] Security updates are applied (if using CMS)

### 🔹 Version Control

- [ ] All changes are committed to Git
- [ ] Repo is backed up (if private) or public (if open source)
- [ ] README is updated with project details

### 🔹 SEO Monitoring

- [ ] Search Console is checked for crawl errors
- [ ] Search Console is checked for mobile usability issues
- [ ] Core Web Vitals are monitored

## Final Project: Website Portfolio

### Project Brief

You have learned how to build a complete, responsive, accessible website using HTML, CSS, and JavaScript. For your final project, you will create a **personal portfolio website** that showcases your skills and demonstrates everything you have learned.

### Requirements

**1. Structure (HTML)**

- [ ] Semantic HTML5 tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`)
- [ ] At least 3 pages (Home, About, Projects/Portfolio)
- [ ] Proper heading hierarchy
- [ ] Form with validation

**2. Style (CSS)**

- [ ] External CSS file
- [ ] Consistent colour scheme and typography
- [ ] Responsive layout (mobile, tablet, desktop)
- [ ] CSS variables used for theming
- [ ] Flexbox or Grid for layout

**3. Interactivity (JavaScript)**

- [ ] At least one interactive feature:
  - Form validation
  - Image gallery or carousel
  - Dark mode toggle
  - Collapsible sections
  - Navigation toggle (mobile hamburger menu)
  - Filterable portfolio

**4. SEO & Accessibility**

- [ ] Descriptive title and meta description on each page
- [ ] Alt text on all images
- [ ] Proper heading hierarchy
- [ ] Keyboard-navigable
- [ ] Good colour contrast

**5. Publishing**

- [ ] Site published on GitHub Pages (or similar)
- [ ] robots.txt file created
- [ ] 404 page created (if possible on platform)
- [ ] Google Analytics tracking installed

### Submission Requirements

1. **GitHub Repository:** All project files
2. **Live Link:** URL of published site
3. **README.md:** Project overview, techniques used, challenges faced
4. **Reflection:** What you learned from this unit

### Reflection Prompts

Use these prompts to guide your reflection:

1. **What was the most challenging part of building this website?**

2. **What are you most proud of in your project?**

3. **How did your understanding of web development change?**

4. **What would you do differently if you started over?**

5. **What is one thing you still want to learn about web development?**
